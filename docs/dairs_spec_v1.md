# D-AIRS v1 仕様書 (draft v0.1)

> ステータス: **仕様書ドラフト（承認待ち）** / 対象: B3 d-airs-dashboard / 作成: 2026-07-09
> D-AIRS = Digital-identity AI Readiness Score（仮称・商標化候補）

## 0. 目的

企業のAIツール**定着度**を継続計測し、経営層が月次で現在地を把握できるようにする。
研修会社（教えるまで）/ SIer（作るまで）と異なり、**導入後の定着を独自指標で科学する**のが差別化。

## 1. スコア構成（0–100 = 4ドメイン加重平均）

重み・閾値は `formula.yaml` で管理し、**バージョン番号をスコアにひも付ける**（経時比較性）。

| ドメイン | 内容 | 0–100 の算出 |
|---------|------|-------------|
| A1 Adoption 利用 | WAU/対象者、7日/30日継続率 | 継続率と利用率の平均×100 |
| A2 Application 深さ | 用途分類の段階(定型文→分析→意思決定支援) | (平均段階/3)×100 |
| A3 Ability スキル | 四半期サーベイ(15問)＋研修受講率 | サーベイ正答率と受講率の平均 |
| A4 Assurance ガバナンス | ルール整備・周知・インシデント運用チェックリスト | 充足率×100 |

初期重み(formula.yaml): A1=0.3, A2=0.3, A3=0.2, A4=0.2

## 2. プライバシー設計（必須）

- **個人別スコアは表示せず、最小集計単位=5名**。5名未満のセグメントは数値をマスク。
- プロンプト原文はサーバに保存しない（用途カテゴリ推定後に破棄）。
- 用途分類はオンプレ集計 or サーベイ回答から算出。

## 3. 介入レコメンドと効果測定

- スコアパターン→施策のルールマッピング（`rules.yaml`）。施策は当社研修・伴走メニュー（`actions_master.yaml`）に対応付け、提案書貼付形式で出力。
- 効果測定モード: 介入群/非介入群の前後スコア差分を表示（「因果とは言えない」注記を自動付与）。

## 4. 受け入れ基準

- 「導入2ヶ月後にWAU半減」の部署が離脱検知に表示されること。
- 5名未満セグメントがマスクされること（テスト担保）。
- `formula.yaml` バージョン変更時、過去スコア再計算と旧版参照が両立すること。
- 介入レコメンド全出力に対応施策マスタIDがひも付くこと（施策の創作なし）。
